# Doll App 🎀

A pet project for doll collectors and hobbyists.

**Doll App** is a platform for collecting doll-related wishlists and organizing items you want to buy. In the future, the project may include tutorials, useful links, a community space, and a Telegram bot.

## Features

* **Wishlist** — add, view, update, and delete wishlist items.
* **Item status tracking** — keep track of items you want to buy and their current status.
* **Tutorials** *(planned)* — collect useful guides and links.
* **Telegram bot** *(planned)* — interact with the platform through Telegram.
* **Community features** *(planned)* — share interests and connect with other collectors.

## Tech Stack

* **Backend:** Kotlin, Spring Boot
* **Database:** PostgreSQL
* **Frontend:** React, TypeScript *(planned)*
* **Telegram Bot:** Python *(planned)*
* **Testing:** JUnit 5, MockK *(planned)*

* Develop automated tests for the backend.
